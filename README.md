# 競馬ノート

競馬の **予想（期待値の計算）** と **馬券の収支記録・分析** を1つにまとめたWebアプリです。
`index.html` をブラウザで開くだけでも使えます（オッズは手入力）。

## オッズを自動で取得する場合

**おすすめ：Macにログインしたら自動で起動させる（1回だけ設定）**

```bash
bash install-mac.command
```

以後は **http://localhost:8765** をブックマークして開くだけ。ターミナル操作は不要です。
アプリ本体は `~/KeibaNote` にコピーされます。

**更新**: 新しいバージョンが出ると、画面上部に「⬆ 新しいバージョンに更新」ボタンが出ます。押すだけで最新版を取り込み、自動で再起動します（記録・学習データはそのまま）。取得元は GitHub の公開リポジトリ（`server.py` の `UPDATE_REPO` / `UPDATE_BRANCH`）です。
解除は `bash uninstall-mac.command`。

**iPhoneで使う**

設定タブの「📱 iPhoneで使う」→「iPhoneから使えるようにする」を押し、表示されたQRコードをiPhoneのカメラで読み取ります（Macと同じWi-Fiで、Macが起動している間だけ使えます）。Safariの共有ボタン →「ホーム画面に追加」でアプリのように使えます。馬券の記録・予想の振り返り・設定はMac（`.cache/state.json`）に保存され、MacとiPhoneで自動で同期します。合言葉入りのQRコードを読み取った端末だけが接続できます。

**外出先・Macを起動していなくても使う（クラウド版）**

[CLOUD.md](CLOUD.md) の手順で、Railway などのクラウドに置けます（月5ドル程度）。どの端末からでも同じ記録を使え、オッズの自動記録も24時間続きます。

**都度起動する場合：ダブルクリック**

- Mac: `start.command` をダブルクリック（初回は右クリック →「開く」）
- Windows: `start.bat` をダブルクリック

ブラウザが自動で開きます。使い終わったら黒い画面（ターミナル）を閉じれば終了です。

**コマンドで起動する場合**

```bash
python3 server.py          # Mac
py server.py               # Windows（python3 ではなく py または python）
python3 server.py --mock   # 架空データで動作確認（ネット接続なし）
```

必ず `server.py` がある keiba フォルダの中で実行してください。既に起動中なら、新たに起動せずその画面を開きます。
記録はURL（ポート番号）ごとに保存されるので、ポート番号は変えないでください。

開いた画面の予想タブの「オッズ自動取得」で 開催日 → レース一覧 → オッズ取得。
Python 3.7以降の標準ライブラリだけで動きます（追加インストール不要）。

- 出走馬・単勝オッズを取り込み、入力済みの印・スコアは馬番で引き継ぎます
- 組み合わせ馬券（馬連〜3連単）は券種を選ぶとオッズを取得し、EVを自動計算。「EV順」で割安な買い目を上から表示
- 「1分ごとに自動更新」で締切前のオッズの動きを追えます
- 取得元への負荷を抑えるため、リクエストは1.5秒以上の間隔を空け、結果を30秒キャッシュします

> 取得元は netkeiba の公開ページです。取得元の利用規約に従い、個人利用の範囲で使ってください。
> サイトの仕様が変わると取得できなくなることがあります（`server.py` の解析部分を直す）。
> 安定性や規約面を重視するなら、公式データの JRA-VAN Data Lab（有料・Windows）への切り替えを推奨します。

## 機能

| タブ | できること |
|---|---|
| 予想 | 重賞を選ぶだけで出走馬・オッズ・能力★・過去10年の傾向を取得。**狙い別のおすすめ**（的中重視／バランス／万馬券狙い／10万馬券）で、狙いに合った券種・配当帯の買い目を期待値順に提示し、まとめて記録。本命/対抗/妙味/穴とケリー基準の推奨額をまとめて表示。単勝オッズと自分の評価（印 / スコア）から推定勝率を出し、単勝の期待値・複勝率・ケリー基準の推奨額を表示。馬連・ワイド・馬単・3連複・3連単の推定的中率と「この倍率以上なら買い」となるオッズも表示 |
| 展開予想（予想タブ） | 近走の位置取り（1コーナー通過順）・逃げた割合・タイム指数・上がりから、逃げ候補とペース（スロー〜ハイ）を予想し、序盤の隊列 → 直線の伸びを図で表示。展開が向く馬・不利な馬に印 |
| 馬券記録 | 購入した馬券を記録・編集・検索。予想タブの「記録へ」から買い目と予想EVを自動入力 |
| 成績分析 | 回収率・収支・的中率・最大連敗・最大ドローダウン・累積収支グラフ。券種・競馬場・自信度・**予想EV帯**・月ごとの集計 |
| 設定 | 運用資金、ケリー係数、1レースの上限額。JSON/CSVの書き出し、JSONの読み込み |

## 能力★とレース傾向（オッズ取得時に自動表示）

- **能力★**: 近5走の「クラスの基準点 − 勝ち馬との着差（秒）」を、新しい走ほど重く・今回と違う馬場/距離は軽く平均した能力値を、レース内での相対評価で★1〜5に変換。「能力値をスコアに反映」で予想モデルの入力にできる
- **レース傾向**: 重賞・特別戦は同じレースの過去10年、条件戦は同時期・同競馬場・同コースの過去レースから、荒れ度（3連単中央値）・1番人気の成績・枠番別/馬番内外/脚質別/人気別の3着内率を集計。有利な枠・脚質は出走馬表でも色付け
- 過去レースのページは `.cache/` に保存するため、2回目以降は通信なしで即表示

## バックテスト（検証タブ）

過去のレースで「その時点の近5走」から能力値を計算し、実際の結果・最終オッズと突き合わせて検証します。

- 能力★別の勝率・複勝率・回収率（★が高いほど走っているか）
- 能力1位 vs 1番人気、「過小評価馬（能力順位が人気より3つ以上上）」の回収率（オッズに勝てる情報か）
- 予想モデルの設定（自分の重み × 基準EV）別の単勝回収率。前半期間で選んだ最適設定を後半期間で確認する（過学習チェック）。良ければワンクリックで予想タブに反映
- 推定勝率と実際の勝率の当てはまり

注意: オッズは最終オッズを使うため、実際に購入する時点のオッズとは差があります。取得したレースは `.cache/` に保存され、2回目以降は高速です。

## 学習モデル（検証タブ）

バックテストで集めたレースから、条件付きロジット（Benter方式）で各要素の重みを学習します。

- 材料: オッズ（市場確率）、能力値、前走の内容、近5走のベスト、前走着順、休養日数、同条件の3着内率、キャリアの浅さ
- 前半70%で学習し、残り30%で「オッズだけの予想」と対数損失を比較。上回ったときだけ予想に使える
- 正則化の強さは学習期間内の検証で自動選択し、市場をはっきり上回れない場合は市場寄りにする（偶然に乗らない）
- 予想タブの「予想のしかた」で 学習モデル／自分の印 を切り替え

## 予想モデルの仕組み

1. **市場確率**: 単勝オッズの逆数を合計1になるよう揃え、控除率の影響を除く
2. **自分の確率**: スコア(0〜100)をsoftmaxで確率にする（「メリハリ」で効き方を調整）
3. **合成**: `p ∝ 自分の確率^w × 市場確率^(1−w)`（Benter方式の対数線形ブレンド）
4. **組み合わせ馬券**: 補正Harvilleモデル（2着は勝率^0.9、3着は勝率^0.8で計算。元のHarvilleは人気サイドを約3割過大評価するため）で着順の確率を出し、各券種の確率を計算
5. **期待値**: `EV = 推定確率 × オッズ`。推奨額は `資金 × ケリー比率 × 係数`

予想EV帯別の回収率を見ると、モデルが本当に当たっているかを確かめられます（EVが高い帯ほど回収率が高ければ機能している）。

## 開発

```bash
npm test                              # 計算ロジック
python3 -m unittest tests/test_server.py  # オッズ取得の解析部分
```

データはブラウザの localStorage に保存されます。別の端末へ移すときはJSONで書き出して読み込んでください。
